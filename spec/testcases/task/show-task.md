# テストケース: ShowTask(show)

参照元: [ユースケース: Task — ShowTask](../../usecases/task.md)

関連仕様: [requirements §10](../../requirements.md)、[pages show・縮退表](../../pages/index.md)、[domains/task](../../domains/task.md)、[scenario/monitoring](../../scenario/monitoring.md)、ADR-014・015

## 正常系

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 登録直後で一度も実行されていない現役タスクがある | 詳細を表示する | ワークフロー名・対象・タスクステータス・実行状態・カウンタ・更新日時が表示され、workspace は「未作成」、attempt は「なし」として 0 で終了する | |
| 実行履歴のある現役タスクがある | 詳細を表示する | 現在attemptの番号・runディレクトリパス・stdout / stderr ログのパスが表示される(ログ確認の起点) | |
| running のタスクがある | 詳細を表示する | PID・kill同定子・starttime が表示され、どのattemptが動いているかが特定できる | |
| launching で同定情報が未取り込みのタスクがある | 詳細を表示する | PID・starttime 等の該当項目が「未取得」として表示され、エラーにしない | |
| 現在attemptの exit ファイルが存在する | 詳細を表示する | exit の値が読み取られて表示される | |
| ツール操作の失敗(worktree 作成失敗等)で凍結した stopped タスクがある | 詳細を表示する | 凍結要因(`StopReason`)と notified_at、直近の失敗要因(`last_failure` の FailureNote)が表示される | |
| エージェント実行の失敗で凍結した stopped タスクがある | 詳細を表示する | 凍結要因(`StopReason`)と notified_at、直前実行の exit・runディレクトリ(ログ)への参照が表示される(FailureNote はエージェント実行自体の失敗を記録しないため、`last_failure` の表示は要求しない) | |
| 未通知(`notified_at` なし)の stopped タスクがある | 詳細を表示する | notified_at が未記録であることが確認できる(at-least-once の検証に使える) | |
| スナップショットが読めるタスクがある | 詳細を表示する | スナップショットの定義済みステータス一覧が表示される(set-status の遷移先確認に使う) | |
| タスクがある | 詳細を表示する | スナップショット保存先としてタスクファイル自体のパス(`state/tasks/<task-id>.json`)が表示される(ADR-015) | |
| `retries` 上書きのあるエージェント実行ステータスのタスクがある | 詳細を表示する | attempt_count に上書き値のリトライ上限が併記される | |
| `retries` 上書きのないエージェント実行ステータスのタスクがある | 詳細を表示する | 組み込みデフォルト 2 がリトライ上限として併記される | |
| クリーンアップステータスのタスクがある | 詳細を表示する | リトライ上限は常に 2 として併記される(ADR-014) | |
| 「何もしない」ステータスのタスクがある | 詳細を表示する | リトライ上限は併記されない(`NotApplicable`。適用対象がない) | |
| config に `judge_attempt_limit` / `spawn_fail_limit` が設定されている | 詳細を表示する | judge・spawn の上限は動作種別・スナップショットによらず常に config の値で表示される | |
| アーカイブ済みタスクのIDを指定する | 詳細を表示する | 現役 → アーカイブの順で解決され、アーカイブ済みであること・worktree は削除済みであることを明示して 0 で終了する(pages ※4) | |
| アーカイブ済みタスクを表示する | 保存先パスを確認する | `state/archive/<task-id>.json` が表示される | |

## 異常系

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| config.yaml が存在しない・パース不能・読めないのいずれか | 詳細を表示する | 非0で終了する(pages ※1) | |
| 指定IDのタスクが現役にもアーカイブにも存在しない | 詳細を表示する | タスク不在として非0で終了する(無言で空を返さない) | |
| 指定IDのタスクファイルがパース不能(`Corrupt`) | 詳細を表示する | パースエラーの内容とファイルパスを表示して非0で終了する(直接修復の導線) | |
| 現在attemptの exit ファイルの読み取りが I/O エラー・内容不正で失敗する | 詳細を表示する | 当該項目を読めない旨の注記付きで表示は継続し、0 で終了する | |
| runディレクトリの存在確認が I/O エラーで失敗する | 詳細を表示する | 当該項目を読めない旨の注記付きで表示は継続し、0 で終了する | |
| タスクIDとして不正な文字列を指定する | 詳細を表示する | 入力境界の検証エラーとして非0で終了する | |

## 境界値

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| タスクIDに空文字列を指定する | 詳細を表示する | 検証エラー(`Empty`)として非0で終了する | |
| タスクIDに65文字の文字列を指定する | 詳細を表示する | 検証エラー(`TooLong`)として非0で終了する | |
| 64文字・1文字の有効なIDを持つタスクがある | 詳細を表示する | 受理されて詳細が表示される | |
| タスクIDに `[a-z0-9-]` 以外の文字を含む・先頭が `-` の文字列を指定する | 詳細を表示する | 検証エラー(`InvalidChar` / `InvalidLeadingChar`)として非0で終了する | |

## エッジケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| スナップショットのみ読めないタスク(`SnapshotUnreadable` / DegradedTask)がある | 詳細を表示する | 読める項目はすべて表示し、スナップショットが読めない理由を注記し、定義済みステータス一覧は表示せず、0 で終了する(pages ※6) | |
| DegradedTask を表示する | リトライ上限の併記を確認する | `Unknown`(スナップショット破損で導出不能)として表示され、Wait の「併記なし」(`NotApplicable`)と区別できる | |
| DegradedTask を表示する | judge・spawn の上限を確認する | スナップショット非依存のため config の値で通常どおり表示される | |
| 現在attemptのrunディレクトリが gc で削除済み | 詳細を表示する | runディレクトリが「存在しない」ことを明示して 0 で終了する(エラーにしない) | |
| launching 記録直後のクラッシュ等で現在attemptのrunディレクトリが未作成 | 詳細を表示する | 「存在しない」表示で 0 で終了する | |
| worktree が手動削除された現役タスクがある | 詳細を表示する | workspace_path をそのまま表示し、存在検証は行わない(pages ※9) | |
| `state/tasks/`・`state/archive/` ディレクトリが存在しない | 詳細を表示する | タスク不在として非0で終了する(pages 縮退表) | |
| 別の操作が排他ロックを保持している | 詳細を表示する | ロックを取得しないため通常どおり表示され 0 で終了する | |
| tick による更新と同時に読み取る | 詳細を表示する | 更新はアトミック置換のため、書きかけの内容が観測されることはない | |
| spawn失敗で pending へ戻った痕跡(無効化マーカーのみのattempt)を持つタスクがある | 詳細を表示する | タスクファイルが指す現在attemptのパスが表示され、過去の残骸と取り違えない起点になる | |
| 登録後の config.yaml 編集による展開失敗の連続で凍結したタスク(同期spawn失敗経路。一度も起動していない)がある | 詳細を表示する | 凍結要因 `SpawnFailLimitExceeded`・直近の失敗要因(`SpawnFail`。展開エラーの内容)が表示され、attempt は「なし」(採番されない)。runディレクトリに痕跡が残る猶予経路と判別できる(ADR-016) | |
