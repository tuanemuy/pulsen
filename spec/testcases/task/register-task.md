# テストケース: RegisterTask(add)

参照元: [ユースケース: Task — RegisterTask](../../usecases/task.md)

関連仕様: [requirements §10](../../requirements.md)、[pages add・縮退表](../../pages/index.md)、[domains/definition](../../domains/definition.md)、[domains/task](../../domains/task.md)、ADR-003・005・007・010・013・015

## 正常系

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 有効な config.yaml と `workflows/implement.yaml` があり、対象リポジトリにベースブランチが存在する | ワークフロー名 `implement` とリポジトリ・ベースブランチを指定して登録する | タスクが pending で作成され、タスクIDが表示されて 0 で終了する | |
| 名前指定で登録が成功する | 登録結果を確認する | ワークフロー名は指定した名前になり、解決先パス(`workflows/implement.yaml` の絶対パス)が表示される | |
| `workflows/implement.yaml` に異なる値の `workflow: my-flow` キーがある | ワークフロー名 `implement` を指定して登録する | タスクのワークフロー名は指定した `implement` になる(名前指定では `workflow:` キーは使われない) | |
| YAML に `workflow: my-flow` キーを持つ定義ファイルがある | ファイルパス指定で登録する | タスクのワークフロー名は `workflow:` キーの値(`my-flow`)になる | |
| YAML に `workflow:` キーのない定義ファイル `custom.yaml` がある | ファイルパス指定で登録する | タスクのワークフロー名はファイル名から拡張子を除いた `custom` になる | |
| リポジトリの HEAD がブランチ `main` を指している | ベースブランチを省略して登録する | ベースブランチが `main` に解決されてタスクが作成される | |
| リポジトリにブランチ `develop` が存在する | `--base develop` を指定して登録する | 対象のベースブランチが `develop` として記録される | |
| カレントディレクトリからの相対パスでリポジトリを指定できる状態 | 相対パスの `--repo` で登録する | 絶対パスへ正規化された値が対象として記録される | |
| 登録が成功する | 作成直後のタスクを照会する | タスクステータスは snapshot の `initial`、実行状態は pending、カウンタは全0、workspace・attempt・失敗要因は未設定である | |
| 登録が成功する | 登録後の状態を観測する | 検証済みワークフロー定義のスナップショットがタスクファイルに埋め込まれ、以降の元YAML編集はこのタスクに影響しない(ADR-015) | |
| 登録が成功する | 登録直後のプロセス・実行状態を観測する | エージェント実行は開始されない(実行は次の tick に委ねられる。ADR-007) | |
| ID発行が既存タスクと衝突する | 登録する | IDが再発行されて1回だけ再試行され、登録が成功して 0 で終了する | |
| 同一リポジトリ・同一ワークフローのタスクが既に登録済み | 同じ指定でもう一度登録する | 重複排除されず、独立した別IDのタスクとして登録される | |

## 異常系

いずれのケースでもタスクは作られない(部分的な変更を残さない)。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| config.yaml が存在しない | 登録する | 「グローバルホームが未初期化」である旨と解決後のホームパス・作成が必要であることを表示して非0で終了する | |
| config.yaml がパース不能(構文エラー・未知キー) | 登録する | 構文エラー・重複キーは行・列を、スキーマ違反(未知キー・型不一致)は問題のキーのパスを表示して非0で終了する | |
| config.yaml が存在するが読めない(権限不足等) | 登録する | 実行環境エラーとして非0で終了する | |
| 別の操作が排他ロックを保持している | 登録する | 「別の操作が実行中」として非0で終了する(登録前のためタスクは作られない) | |
| ロック機構自体が異常(`LockError::Failed`) | 登録する | 実行環境エラーとして非0で終了する | |
| 指定した名前に対応する `workflows/<name>.yaml` が存在しない | 名前指定で登録する | 解決を試みた絶対パスを添えて非0で終了する | |
| 指定したファイルパスのワークフロー定義が存在しない | パス指定で登録する | 解決を試みたパスを添えて非0で終了する | |
| ワークフロー定義ファイルが存在するが読めない(I/O障害) | 登録する | 非0で終了する | |
| ワークフローYAMLが構文として不正(重複キー含む) | 登録する | 位置・原因に加えて解決先の絶対パスを表示して非0で終了する(`YamlSyntax`) | |
| ワークフローYAMLにスキーマ外のキーがある | 登録する | 非0で終了する(`UnknownKey`。ADR-013) | |
| `run: wait` のステータスに `judge` 等のエージェント実行用キーがある | 登録する | 非0で終了する(`ForbiddenKey`。ADR-013) | |
| `initial` が欠落している | 登録する | 非0で終了する(`MissingInitial`) | |
| `initial` の参照先ステータスが存在しない | 登録する | 非0で終了する(`InitialNotFound`) | |
| `statuses` が空または欠落している | 登録する | 非0で終了する(`EmptyStatuses`) | |
| 動作宣言(`prompt` / `skill` / `run`)のないステータスがある | 登録する | 非0で終了する(`NoAction`) | |
| 1ステータスに `prompt` と `skill` など複数の動作宣言がある | 登録する | 非0で終了する(`MultipleActions`) | |
| `run` の値が `cleanup` / `wait` 以外 | 登録する | 非0で終了する(`UnknownRunValue`) | |
| エージェント実行のステータスに `next` がない | 登録する | 非0で終了する(`MissingNext`) | |
| `next` の参照先ステータスが存在しない | 登録する | 非0で終了する(`NextNotFound`) | |
| ステータス名・期間・コマンドの値が不正(空文字のプロンプト、`timeout: 0s` 等) | 登録する | 非0で終了する(`InvalidValue`) | |
| `workflow:` キーがなく、ファイル名由来の表示名が不正になるパス(語幹が空白のみになる ` .yaml` 等。`Path::file_stem` は `.yaml` を語幹として返すため「拡張子を除くと空」は作れない) | パス指定で登録する | 表示名の決定失敗として非0で終了する | |
| 指定したリポジトリパスが存在しない | 登録する | 非0で終了する | |
| 指定したパスが git リポジトリでない | 登録する | 非0で終了する | |
| 指定したベースブランチがリポジトリに存在しない | 登録する | 非0で終了する | |
| リポジトリが detached HEAD で `--base` 省略 | 登録する | `--base` の明示指定を案内して非0で終了する | |
| リポジトリがコミットのない空リポジトリで `--base` 省略 | 登録する | `--base` の明示指定を案内して非0で終了する | |
| 対象検証の git 操作自体が失敗する(`TargetError::Failed`) | 登録する | 実行環境エラーとして非0で終了する | |
| ステータスにもワークフローにもエージェント指定がない | 登録する | 非0で終了する(`MissingAgent`) | |
| 実効エージェント名が config の `agents` に存在しない | 登録する | config.yaml に定義済みのエージェント名一覧を添えて非0で終了する(`UnknownAgent`) | |
| 参照エージェントの `cmd` に未知プレースホルダ・波括弧不正がある | 登録する | 非0で終了する(`InvalidAgentDefinition`) | |
| `skill` 指定のステータスがあるがエージェント定義に `skill_input` がない | 登録する | 非0で終了する(`MissingSkillInput`) | |
| `cmd` が `{model}` を参照するがワークフロー・ステータスのどちらにも `model` 指定がない | 登録する | 非0で終了する(`MissingModel`) | |
| 複数のステータスにまたがって登録時検証エラーが複数ある | 登録する | エラーが最初の1件で打ち切られず全件まとめて表示され、非0で終了する | |
| ID再発行後もIDが衝突する | 登録する | 実行環境エラーとして非0で終了する(2回目の再試行はしない) | |
| タスクファイルの作成が I/O エラーで失敗する | 登録する | 実行環境エラーとして非0で終了する | |

## 境界値

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ワークフロー指定値がパス区切り文字を含む(`./flows/x`) | 登録する | ファイルパスとして解決される(ファイルの存在有無に依存しない決定的規則) | |
| ワークフロー指定値が `.yaml` で終わる | 登録する | ファイルパスとして解決される | |
| ワークフロー指定値が `.yml` で終わる | 登録する | ファイルパスとして解決される | |
| ワークフロー指定値がパス区切りも拡張子も含まない | 登録する | 名前として `workflows/<name>.yaml` に解決される(`.yml` へのフォールバックはしない) | |
| ワークフロー指定値が空文字列 | 登録する | 入力境界の検証エラー(`NameError::Empty`)として非0で終了する。タスクは作られない | |
| `--base` に空文字列を指定する | 登録する | ブランチ名の検証エラーとして非0で終了する | |
| `--base` の先頭が `-`、`..` を含む、`/` 始まり・終わり、`.lock` 終わり、空白・制御文字を含むいずれか | 登録する | ブランチ名の検証エラーとして非0で終了する | |
| ステータスに `retries: 0` が指定されている | 登録する | 受理されて登録が成功する(0 = 初回失敗で即 stopped は実行時の意味) | |
| ステータスに `timeout: none` が指定されている | 登録する | 無制限として受理され登録が成功する | |
| ステータスの `timeout` が `0s`・単位なし・負値のいずれか | 登録する | 期間の検証エラーとして非0で終了する | |
| statuses が1件だけの定義 | 登録する | 受理されて登録が成功する | |

## エッジケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| `state/` 配下のディレクトリ(tasks 等)が存在しない | 登録する | 必要なディレクトリが自動作成され、登録が成功する(pages ※3) | |
| `next` に自己参照・循環があるワークフロー定義 | 登録する | 正当な表現として受理され登録が成功する(ADR-010) | |
| 遷移経路のない到達不能ステータス(set-status 用のクリーンアップ等)を含む定義 | 登録する | 受理され登録が成功する | |
| クリーンアップ動作のステータス(終端)を持たない定義 | 登録する | 受理され登録が成功する(循環の出口は人間の操作・stopped) | |
| config.yaml にテンプレートが壊れたエージェント定義があるが、登録するワークフローはそれを参照しない | 登録する | 参照されないエージェント定義は検証されず、登録が成功する(内容の検証は参照時) | |
| エージェント定義に値の供給されるプレースホルダ(`{model}` 等)への参照がなく、値だけが指定されている | 登録する | 許容されて登録が成功する(値は単に渡らない) | |
| ステータスの `judge` コマンドのトークンに `{...}` 形の文字列が含まれる | 登録する | プレースホルダとして検査されず文字どおり受理される(判定コマンドに展開は行われない) | |
| `PULSEN_HOME` と `--home` フラグの両方が指定されている | 登録する | フラグのホームが優先して解決される(フラグ > 環境変数 > 既定) | |
