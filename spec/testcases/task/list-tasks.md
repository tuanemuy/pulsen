# テストケース: ListTasks(ls)

参照元: [ユースケース: Task — ListTasks](../../usecases/task.md)

関連仕様: [requirements §10](../../requirements.md)、[pages ls・縮退表](../../pages/index.md)、[domains/task](../../domains/task.md)、[scenario/monitoring](../../scenario/monitoring.md)

## 正常系

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 異なるワークフロー・タスクステータス・実行状態の現役タスクが複数ある | 絞り込みなしで一覧する | 各タスクのID・ワークフロー名・リポジトリ・ブランチ・タスクステータス・実行状態・attempt_count・更新日時が表示されて 0 で終了する | |
| タスクステータスと実行状態が同名になり得るタスクがある | 一覧する | タスクステータスと実行状態の両方が常に表示され、区別できる | |
| 特定のタスクステータスを持つタスクと持たないタスクが混在する | `--status` で絞り込む | 一致するタスクのみが表示される | |
| 異なる実行状態のタスクが混在する | `--state` に有効値を指定して絞り込む | 一致する実行状態のタスクのみが表示される | |
| `--status` と `--state` の両条件に部分的に一致するタスクが混在する | 両方を指定して一覧する | 両条件を AND で満たすタスクのみが表示される | |
| アーカイブ済みタスクが存在する | 絞り込みなしで一覧する | アーカイブ済みタスクは表示されない(既定は現役のみ) | |
| アーカイブ済みタスクが存在する | `--all` で一覧する | アーカイブ済みタスクも表示され、行にその旨の印が付き、ブランチも表示される | |
| 現役・アーカイブ両方に条件一致タスクがある | `--all` と絞り込みを併用する | 対象集合の拡張(現役+アーカイブ)後に絞り込みが適用される | |
| タスクが1件もない | 一覧する | 空である旨を表示して 0 で終了する | |
| 絞り込み条件に一致するタスクがない | 絞り込み付きで一覧する | 空である旨を表示して 0 で終了する | |

## 異常系

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| config.yaml が存在しない・パース不能・読めないのいずれか | 一覧する | 非0で終了する(pages ※1) | |
| `--state` に固定6値以外の値を指定する | 一覧する | 有効な値の一覧(pending / launching / running / completed / failed / stopped)を添えて非0で終了する | |
| `state/tasks/` の走査自体が I/O エラーで失敗する(権限不足等) | 一覧する | 実行環境エラーとして非0で終了する | |
| `state/archive/` の走査自体が I/O エラーで失敗する | `--all` で一覧する | 実行環境エラーとして非0で終了する | |

## 境界値

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 6つの実行状態それぞれのタスクがある | `--state` に `pending` / `launching` / `running` / `completed` / `failed` / `stopped` を順に指定する | 6値すべてが受理され、それぞれ該当タスクのみが表示される | |
| — | `--state` に大文字混じりの値(`Pending` 等)を指定する | 小文字の6値のみ受理のため、有効値一覧を添えて非0で終了する | |
| — | `--state` に空文字列を指定する | 有効値一覧を添えて非0で終了する | |
| どのタスクにも存在しないタスクステータス名がある | `--status` にその値を指定する | 値は検証されず(ユーザー定義語彙)、該当0件として空の一覧を 0 で返す | |

## エッジケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| パース不能なタスクファイル(`Corrupt`)と正常なタスクが混在する | 一覧する | 破損ファイルはパスと読めない旨として報告され、残りのタスクは表示され、0 で終了する(修復の入口。pages ※5) | |
| スナップショットのみ読めないタスク(`SnapshotUnreadable`)がある | 一覧する | 行として表示され、スナップショット読み取り不能の印が付き、0 で終了する | |
| `SnapshotUnreadable` のタスクが絞り込み条件に一致する | `--status` / `--state` で絞り込む | 実行状態・タスクステータスは読めているため、絞り込みの対象になる | |
| `state/tasks/` ディレクトリが存在しない | 一覧する | 空の一覧として 0 で終了する(pages 縮退表) | |
| `state/archive/` ディレクトリが存在しない | `--all` で一覧する | アーカイブ分は空として扱われ、現役のみ表示して 0 で終了する | |
| アーカイブ側にパース不能なタスクファイルがある | `--all` で一覧する | 一覧全体を失敗させず、読み取り不能として報告される | |
| 別の操作が排他ロックを保持している | 一覧する | ロックを取得しないため通常どおり一覧が表示され 0 で終了する | |
| tick による更新と同時に読み取る | 一覧する | 更新はアトミック置換のため、書きかけの内容が観測されることはない | |
