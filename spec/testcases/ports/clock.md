# 適合テスト: Clock

対象の契約: [Task ドメイン: Clock](../../domains/task.md#clock)(関連: [Timestamp](../../domains/task.md#timestamp))

Clock のすべてのアダプター実装(システム時計・テスト用の可変クロック等)が共通で通す適合テストスイート。契約は「壁時計の現在時刻を返す」ことのみで、単調性は要求されない。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| なし | `now` | `Timestamp` が返る。秒精度の UTC 日時であり、サブ秒成分を持たない | |
| なし | `now` の返値を RFC3339 文字列に直列化して再パースする | 元の `Timestamp` と等価(タスクファイルの直列化表現との往復) | |
| 呼び出しの前後で外部の実時刻を観測できる状態(システム時計を参照し、テスト中に時刻改変が起きないアダプター環境に限る) | 呼び出しの直前・直後に外部で観測した実時刻と比較する | `now` の値が前後の観測時刻の範囲に収まる(秒精度での整合。呼び出し時点の壁時計を返す) | |
| 時刻が進んだ状態(実時間の経過、または時刻を制御できるアダプターでの前進) | 先の `now` の値を保持したまま再度 `now` | 後の値は先の値より後の時刻になり、`elapsed_since` で経過秒数が導出できる | |
| 時刻を先の `now` より過去に巻き戻した状態(時刻を過去に設定できるアダプター環境に限る) | `now` | 設定どおりの(先の値より過去の)時刻が返る(契約は単調性を要求しないため、巻き戻った値を返すことは契約違反ではない) | |

## 対象外

- `now` の非減少(単調性): 契約は単調性を要求しない(壁時計。マシン再起動・時刻合わせで巻き戻り得る)ため、スイートは検証しない
- 巻き戻り時の過大評価防止(経過が負なら 0 として扱う): `Timestamp` / 消費側(猶予時間・timeout 判定)の規則であり、本ポートの契約ではない(ドメインテストが担う)
