# ポート適合テスト: CommandRunner

対象契約: [../../domains/execution.md#commandrunner](../../domains/execution.md#commandrunner)

すべてのアダプター実装が共通で通す。標準出力・標準エラーは捕捉されない契約のため、コマンドの観測結果(受け取った引数・環境変数・作業ディレクトリ)は exit code またはコマンド自身が書き出すファイルで検証するテスト用コマンドをフィクスチャとして用いる。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| exit 0 で終了するテスト用コマンド | `run(cmd, [], None)` | `Exited(ExitCode(0))` | |
| 非0(例: 5)で終了するテスト用コマンド | `run(cmd, [], None)` | `Exited(ExitCode(5))` | |
| 存在しないコマンド名 | `run(cmd, [], None)` | `FailedToStart`(`Exited` の非0 とは区別される) | |
| 実行できない実体(実行権限がないファイル等) | `run(cmd, [], None)` | `FailedToStart` | |
| 実行中に外部から強制終了される(exit code を持たない終了をする)コマンド | `run(cmd, [], None)` | 非0 の符号化値(POSIX慣例では 128+シグナル番号)の `Exited(ExitCode)` を返す(`run_agent` と同じ符号化規則。`TimedOut` / `FailedToStart` にならない) | |
| シェルのメタ文字(`*`・`$VAR`・`&&`・リダイレクト記号等)を引数トークンに含め、受け取った引数がリテラル一致なら 0 を返す検査コマンド | `run(cmd, [], None)` | `Exited(0)`(引数が展開・連結・解釈されずそのまま渡る = シェル機能が効かない直接起動) | |
| `{input}` 等のプレースホルダ文字列を引数トークンに含めた検査コマンド | `run(cmd, [], None)` | `Exited(0)`(プレースホルダ展開は行われず文字どおり渡る) | |
| 呼び出しプロセスに環境変数を設定し、その値を検査するコマンド。`env` 引数は空 | `run(cmd, [], None)` | `Exited(0)`(呼び出しプロセスの環境が継承される) | |
| `env` 引数で新しい変数を与え、その値を検査するコマンド | `run(cmd, env, None)` | `Exited(0)`(`env` の変数が追加される) | |
| 呼び出しプロセスと `env` 引数で同名の変数に異なる値を設定し、`env` 側の値を検査するコマンド | `run(cmd, env, None)` | `Exited(0)`(`env` の値が継承環境を上書きする) | |
| 呼び出しプロセスの作業ディレクトリと一致するか検査するコマンド | `run(cmd, [], None)` | `Exited(0)`(作業ディレクトリは呼び出しプロセスの cwd のまま。ポートは変更しない) | |
| timeout 指定より長く実行し続けるコマンド | `run(cmd, [], Some(短いtimeout))` | `TimedOut`。起動されたプロセスは終了させられている(timeout 後に生存していない) | |
| timeout 内に exit 0 で終了するコマンド | `run(cmd, [], Some(timeout))` | `Exited(0)`(`TimedOut` にならない) | |
| 一定時間実行してから終了するコマンド・timeout 未指定 | `run(cmd, [], None)` | 終了まで待って `Exited`(timeout による打ち切りは発生しない) | |
| 終了直前に完了の証跡(ファイル等)を残すコマンド | `run(cmd, [], None)` | `run` の呼び出しはコマンド終了まで戻らず、戻った時点で証跡が観測できる(同期実行) | |
| 標準出力・標準エラーへ既知の文字列を出力するコマンド | `run(cmd, [], None)` | `CommandCompletion` に出力は含まれず、出力は呼び出しプロセスの標準出力・標準エラーへそのまま流れる(捕捉しない) | |
