# 適合テスト: TaskIdGenerator

対象の契約: [Task ドメイン: TaskIdGenerator](../../domains/task.md#taskidgenerator)(関連: [TaskId](../../domains/task.md#taskid))

TaskIdGenerator のすべてのアダプター実装が共通で通す適合テストスイート。ID の形式(時刻成分・ランダム成分の構成等)はアダプターに委ねられているため、形式そのものは検証せず、契約(文字集合制約の充足と実用上の一意性)のみを検証する。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| なし | `generate` | 返値が `TaskId` の制約を満たす: 1〜64文字、使用文字は `[a-z0-9-]` のみ、先頭は英数字(文字列表現が `TaskId::parse` を通る) | |
| なし | `generate` を多数回(例: 10,000回)呼び出す | すべて制約を満たし、互いに重複しない(実用上の一意性) | |
| なし | 時間間隔を置かず連続して `generate` する | 重複しない(時刻成分のみに依存しない。同一時刻内の連続発行でも区別される) | |
| 同じ構成のジェネレーターを複数用意する | それぞれから `generate` する | 互いに重複しない(インスタンスを跨いでも実用上の一意性が成り立つ) | |
| なし | `generate` した ID からパス・ブランチ名を導出する | `<worktree_root>/<id>`(worktreeパス)・`pulsen/<id>`(`BranchName::parse` を通る)・`<id>.json`(ファイル名主部)がいずれも有効になる(文字集合制約の帰結として常に安全) | |

## 対象外

- 厳密な一意性: 契約が要求しない(`TaskRepository::create` の `Conflict` がバックストップとなり、ユースケースは衝突時に再発行する)
