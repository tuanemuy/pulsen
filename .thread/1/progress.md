# 進捗メモ — Issue #1

実装ステップ1〜20はすべて実装済み。以下は完了後に残るフォローアップと、環境によって挙動が変わる点の記録。

## spec へ追従を提起する点

- **エラー位置の粒度**（ADR-050）: spec/testcases/task/register-task.md の異常系は「config.yaml がパース不能(構文エラー・未知キー)→ エラー位置を表示」と書くが、ADR-021 の読み込み方（`Value` 化してから手書き走査）では行・列が取れるのは構文解析までで、スキーマ違反には行・列が残らない。実装は構文エラーに行・列を、スキーマ違反にファイルパスと論理位置（キーのパス）を示す。spec 側の語を「構文エラーは行・列、スキーマ違反はキーのパス」へ言い換える提案を Issue のコメントに残す。
- **表示名を決められないファイル名の例示**（ADR-051）: spec は「拡張子を除くと空になるファイル名等」と例示するが、Rust の `Path::file_stem` は `.yaml` を語幹として返すため「拡張子を除くと空」は作れない。受け入れテストは語幹が空白のみになるファイル名（` .yaml`）で再現している。spec の例示に「語幹が空白のみ」を含める提案を Issue のコメントに残す。
